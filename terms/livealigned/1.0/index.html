この利用規約（以下「本規約」といいます。）は、株式会社オートインフラ（以下「当社」といいます。）が提供する「LiveAligned」（以下「本サービス」といいます。）の利用条件を定めます。

第1条（適用・同意）

  1. 本規約は、本サービスの利用に関する当社と利用者との間の一切の関係に適用されます。
  2. プライバシーポリシー、コミュニティガイドラインおよび本サービス上で表示する個別条件は、本規約の一部を構成します。
  3. 利用者は、本規約、プライバシーポリシーおよびコミュニティガイドラインを確認し、同意した上で本サービスを利用します。

第2条（年齢および利用資格）

  1. 16歳未満の方はアカウントを作成できません。
  2. 16歳または17歳の利用者には、投稿、購入、予約、問い合わせその他の機能について、成人利用者と異なる読み取り専用その他の制限が適用されます。
  3. 利用者は、正確な生年月日その他必要な情報を提供し、他人になりすましてはなりません。
  4. 法令、本規約または過去の措置により利用を認められない方は、本サービスを利用できません。

第3条（アカウント）

  1. 本サービスは、匿名アカウントまたはメールアドレス等で確認された登録アカウントを提供する場合があります。
  2. 利用者は、自身の端末、メールアドレス、認証コードおよびセッションを適切に管理します。
  3. 認証コード、パスワード、アクセストークンその他の認証情報を第三者へ提供してはなりません。
  4. アカウントの不正利用を知った場合は、速やかに当社へ連絡してください。

第4条（本サービス）

本サービスは、プロフィール、投稿、画像・動画、フォロー・リアクション等の交流、店舗情報、予約、問い合わせ、カルテ、商品・サービス、ギフトその他の機能を提供する場合があります。利用できる機能は、年齢、所属、役割、店舗設定、地域、端末、アプリバージョン等により異なります。

第5条（利用者コンテンツ）

  1. 利用者は、自ら権利を有し、または必要な許諾を得たコンテンツのみを投稿できます。
  2. 利用者コンテンツの権利は、利用者または従前の権利者に留保されます。
  3. 利用者は当社に対し、本サービスの提供、保存、表示、配信、サイズ変更、技術的変換、モデレーション、セキュリティおよび改善に必要な範囲で、利用者コンテンツを利用する非独占的な権利を許諾します。
  4. 前項の許諾は、本サービスの提供に必要な範囲を超えて利用者コンテンツを販売する権利を意味しません。
  5. 利用者は、コミュニティガイドラインを遵守します。

第6条（禁止事項）

利用者は、次の行為を行ってはなりません。

  1. 法令、公序良俗、本規約またはコミュニティガイドラインに違反する行為
  2. 児童への性的虐待・搾取、CSAM、グルーミング、性的脅迫、人身取引に関する行為
  3. 暴力、脅迫、自傷・自殺の助長、差別、嫌がらせ、いじめ、露骨な性的表現を投稿する行為
  4. 他者の知的財産権、肖像権、プライバシー、名誉その他の権利を侵害する行為
  5. なりすまし、詐欺、虚偽情報、スパム、不正な勧誘または不正な取引
  6. 個人情報、認証情報、秘密情報を権限なく収集、公開または利用する行為
  7. 本サービスへの不正アクセス、過度な負荷、リバースエンジニアリング、脆弱性の悪用
  8. 通報、ブロック、年齢制限、認可、課金その他の保護機能を回避する行為
  9. その他、利用者または本サービスの安全を害する行為

  1. 利用者は、本サービス内の機能からコンテンツまたは利用者を通報し、利用者をブロックできます。
  2. 当社は、通報の有無にかかわらず、コンテンツの非表示・削除、機能制限、警告、アカウント停止・削除、証拠保全、関係機関への通報その他必要な措置を行うことがあります。
  3. 緊急対応、捜査、被害者保護または濫用防止のため、措置の理由や詳細を開示できない場合があります。
  4. 具体的な基準はコミュニティガイドラインに定めます。
