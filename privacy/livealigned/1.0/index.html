LiveAligned プライバシーポリシー

株式会社オートインフラ（以下「当社」といいます。）は、当社が提供するアプリケーション「LiveAligned」（以下「本サービス」といいます。）における利用者情報を、本ポリシーに従って取り扱います。

1. 運営者

  • 事業者名：株式会社オートインフラ
  • 所在地：東京都新宿区新宿1-36-2 新宿第七葉山ビル3F
  • 連絡先：support@autoinfra.jp

2. 適用範囲

本ポリシーは、本サービスのアプリ、Webページ、認証、サポート、アカウント削除、コンテンツ配信、予約・問い合わせ、決済その他本サービスに付随する機能へ適用されます。

3. 取得する情報

当社は、利用する機能に応じて次の情報を取得します。

3.1 アカウント・年齢確認情報

  • 匿名アカウントまたは登録アカウントの識別子
  • 登録時または本人確認時のメールアドレス
  • 生年月日および生年月日から判定される年齢区分
  • 認証、セッション、法務文書への同意履歴
  • 所属店舗、役割、権限に関する情報

3.2 プロフィール・利用者コンテンツ

  • ユーザー名、表示名、プロフィール画像、自己紹介、所在地、Webサイト等
  • 投稿本文、画像、動画その他利用者が送信するコンテンツ
  • フォロー、リアクション、ブックマークその他の利用履歴

3.3 店舗・予約等の情報

  • 店舗、スタッフ、予約、問い合わせに関する情報
  • 利用者がカルテ機能等へ入力または提供する情報
  • 商品、サービス、取引に関する情報

3.4 決済・ギフト等の情報

  • ギフト、チップ、購入、返金等の取引識別子、金額、日時、状態
  • Apple App StoreまたはGoogle Playが発行する購入検証情報
  • Stripe等の決済事業者が発行する取引結果

当社は、Apple、Google、Stripe等の決済事業者が管理するクレジットカード番号その他の決済手段情報を直接取得または保管しません。

3.5 安全管理・モデレーション情報

  • 通報、ブロック、ミュート、違反対応、異議申立てに関する情報
  • 不正利用防止のためのアクセス記録、IPアドレスまたはそのハッシュ、レート制限記録
  • 法令違反、児童の安全その他重大な安全上の問題に関する調査記録

3.6 技術・利用状況情報

  • 端末、OS、アプリバージョン、言語、ネットワーク等の技術情報
  • 操作履歴、エラー、クラッシュ、同期状態、アクセスログ
  • 画像・動画等の配信、キャッシュおよびセキュリティに必要な情報

4. 利用目的

当社は、取得した情報を次の目的で利用します。

  1. 本サービスの提供、認証、同期、コンテンツ配信およびサポート
  2. 年齢に応じた利用制限、権限管理および法務文書への同意管理
  3. 投稿、予約、問い合わせ、店舗機能、ギフト、購入等の処理
  4. 不正利用、迷惑行為、権利侵害、児童への性的虐待・搾取その他の安全上の問題の防止と対応
  5. 障害対応、品質改善、セキュリティ維持および監査
  6. アカウント削除、利用者からの請求および法令上の義務への対応

5. 外部サービスおよび委託先

当社は、目的達成に必要な範囲で、次の種類の事業者へ情報の取扱いを委託し、または情報を送信します。

  • Supabase：認証、データベース、サーバー機能、ストレージ
  • Cloudflare：画像・動画の保存、処理、配信およびセキュリティ
  • Amazon Web Services / Amazon CloudFront：コンテンツ配信、キャッシュ無効化等
  • Apple / Google：アプリ配信、認証、アプリ内課金、購入検証
  • Stripe：対象となる商品・サービスの決済処理

委託先のサーバーが日本国外に所在する場合があります。当社は、適用法令および契約に従い、委託先に必要な安全管理を求めます。当社は利用者情報を販売しません。法令に基づく場合、人の生命・身体の保護に必要な場合、または利用者の同意がある場合を除き、上記目的と無関係な第三者提供を行いません。

6. 安全管理措置

当社は、通信の暗号化、アクセス制御、行単位の認可、認証情報の安全な保管、ログ監査、権限分離、端末データの消去等、利用者情報の性質に応じた安全管理措置を講じます。

7. 保存期間

当社は、利用目的の達成、契約の履行、セキュリティ、不正防止、会計、紛争対応および法令上の義務に必要な期間に限って情報を保存します。

  • 通常のアカウント情報と利用者コンテンツ：アカウント存続中および削除処理に必要な期間
  • 利用実績のない匿名アカウント：最後の意味のある利用から365日間利用がなく、法務・決済等の保留がない場合に削除対象とします。メールアドレスのない匿名アカウントには事前通知できない場合があります
  • 法務同意、会計、不正防止、監査、通報対応等：アカウントとの直接の結び付きを削除または仮名化した上で、適用法令および目的に必要な最小期間保存する場合があります

8. アカウントとデータの削除

利用者は、アプリ内のアカウント設定またはLiveAligned アカウント削除から、アカウントと関連データの削除を要求できます。サインアウトやアプリのアンインストールだけでは、サーバー上のアカウントは削除されません。

削除時は、プロフィール、投稿、画像、動画、利用履歴その他アカウントに関連する情報を削除します。ただし、会計、不正防止、法的義務、権利保護等のため保存が必要な情報は、アカウントから切り離して匿名化または仮名化し、必要最小限の期間保存する場合があります。

9. 利用者の権利

利用者は、適用法令に従い、自身の個人情報について、開示、訂正、利用停止、削除その他の請求を行えます。請求時には、第三者による不正請求を防ぐため、合理的な本人確認をお願いする場合があります。

10. 年齢に関する方針

本サービスは16歳未満の方によるアカウント作成を認めません。16歳または17歳の利用者には、成人利用者と異なる読み取り専用その他の制限が適用されます。当社が16歳未満の方のアカウント作成を把握した場合、当該アカウントと関連データを削除します。

11. 本ポリシーの変更

本ポリシーを変更する場合、変更内容と適用日を本サービスまたは公開ページで通知します。重要な変更では、適用前に改めて確認または同意を求める場合があります。同意記録に用いる版の本文は、versioned URLで保持します。

12. お問い合わせ

本ポリシーまたは利用者情報の取扱いに関するお問い合わせは、support@autoinfra.jpへご連絡ください。
